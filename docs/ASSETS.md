# Local demonstration assets

The community members and events are fictional sample data, not real musician endorsements. Replace sample profiles, photos, and portfolio content with consented material before real use.

Concert photographs (`public/images/poster-*.jpg`) are distributed by Sadee's MIT-licensed music-player example:
https://github.com/codewithsadee/music-player (commit 1e1ffb4d6fad2cea6ba3e604ccddcc0d68f3dc4f).
The included license is in `public/licenses/music-player-MIT.txt`.

Sample portraits (`public/images/team-*.jpg`) are distributed with Creative Tim's Soft UI Dashboard (MIT):
https://github.com/creativetimofficial/soft-ui-dashboard (commit 8d29eaac504f62240b5c7be56c93b27848280f77).
The included license is in `public/licenses/soft-ui-dashboard-MIT.txt`.

DM Sans and Space Grotesk are bundled through @fontsource packages, under their included SIL Open Font Licenses. No external font requests are necessary. Brand illustrations (record, poster, waveforms) are original CSS and Lucide icons (ISC license in lucide-react).
